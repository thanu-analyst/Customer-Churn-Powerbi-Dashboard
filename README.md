 ## Project
Customer churn dashboard on Telco dataset (7,043 customers), built in Power BI.

## Tools
Power BI, DAX

## Key findings
- About 26.5% of customers churned
- 88.55% of churned customers were on month-to-month contracts
- Electronic check was the most common payment method among churned customers
- New customers with short tenure churn the most

## Recommendation
Offer discounts to move month-to-month customers to 1-2 year contracts
